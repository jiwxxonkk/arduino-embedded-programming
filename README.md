# Arduino Embedded Programming

A collection of Arduino-based embedded programming exercises focused on hardware interfacing, sensor data processing, and numerical methods.

## Overview

This repository contains practical exercises exploring fundamental concepts of embedded systems programming using Arduino as part of the Software Project I course.

The exercises cover basic digital I/O operations, sensor interfacing, data filtering, and numerical computations.

## Topics Covered

- Digital I/O and LED control
- Serial communication
- Analog sensor interfacing
- IR sensor data acquisition and filtering
- Memory usage and execution time analysis
- Polynomial regression and curve fitting

## Technologies

- Language: C/C++
- Platform: Arduino
- Development Environment: Arduino IDE

## Repository Structure

The repository contains individual Arduino sketches (`.ino`) developed for programming exercises and experiments.

## Purpose

To develop a practical understanding of embedded systems programming through hands-on experiments involving hardware control, sensor measurements, and data processing.
